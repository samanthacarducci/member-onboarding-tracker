# 90-Day Executive Onboarding & Retention Tracker

**An end-to-end operational analytics solution connecting billing, CRM, member engagement, and retention data to actionable business intelligence.**

## The Business Problem

Understanding customer retention requires more than tracking cancellations. Teams need visibility into how customers onboard, which behaviors indicate successful activation, and where early intervention could improve retention.

I built this solution to bring those signals together, connect customer behavior to renewal outcomes, and give operational teams a clearer picture of customer health.

## System Architecture

**Chargebee → Salesforce → Google Sheets → Claude → GitHub → Netlify**

The solution connects multiple technologies to turn operational data into an accessible analytics application.

| Technology | Role |
|---|---|
| **Chargebee** | Subscription and billing data |
| **Salesforce** | Central CRM and member lifecycle records |
| **Google Sheets** | Data preparation and reporting layer |
| **Claude** | AI-assisted application development and iteration |
| **GitHub** | Source code management and version control |
| **Netlify** | Web application hosting and deployment |

## Key Capabilities

- **Activation scoring:** Weighted onboarding milestones and engagement signals classify members by activation stage.
- **Cohort analysis:** Monthly cohort views track retention trends and onboarding performance.
- **Churn risk identification:** Low engagement and cancellation indicators help identify members requiring attention.
- **Renewal intelligence:** Compares retention outcomes across activation tiers and onboarding milestones.
- **Interactive reporting:** Searchable member records, filters, visualizations, and drilldowns connect executive-level reporting to individual customer activity.

## Technical Implementation

- HTML, CSS, and JavaScript
- Chart.js for interactive data visualizations
- Custom activation scoring and cohort analysis logic
- Cross-system data flow spanning billing, CRM, and reporting
- AI-assisted development using Claude
- GitHub-based version control and Netlify deployment
